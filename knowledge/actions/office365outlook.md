# Office 365 Outlook

出典: https://learn.microsoft.com/ja-jp/power-automate/desktop-flows/actions-reference/office365outlook （Microsoft Docs, CC BY 4.0 https://creativecommons.org/licenses/by/4.0/ — 本プロジェクトによる要約・圧縮。Microsoft の見解ではない。LEGAL.md 参照）

概要: The Office 365 Outlook group of actions allows the utilization of the Office 365 Outlook connector from within desktop flows, alleviating the need to create a cloud flow in order to use its actions. This connector is the same as the one used across Power Automate cloud flows, Power Apps, and Logic Apps. It uses the same parameters and returns the same type of data.

## Prerequisites and limitations
- You need an Attended RPA license.
