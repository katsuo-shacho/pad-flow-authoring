# 計画: csv-to-excel（お題: フォルダー内の CSV を1つの Excel に結合して保存、処理済みを移動）

目的 / 入力 / 出力 / 制約 / 禁止
- 目的: 取込フォルダーに溜まる CSV（同じ列構成）を毎朝1本の Excel にまとめる
- 入力: `C:\Work\csv-in\*.csv`（既定値。件数 1〜50）。1行目は列名
- 出力: `C:\Work\out\combined.xlsx`。処理済み CSV は `C:\Work\csv-done` へ移動
- 成功判定: xlsx が存在し、行数 = 各 CSV の行数の合計。ログ末尾に「完了: n 件結合」
- 制約: PAD 2.73 / Classic / 有人（デスクトップで利用者が実行）/ Excel あり
- 禁止: 送信系なし。本番データでの検証はしない（テスト用 CSV を用意）
- 既存フロー: なし（新規）

方針（処理順）
1. CSV 一覧を一括取得（0件なら終了）
2. 各 CSV を読み、データテーブルを結合（ループ本体は「読む→結合」の2操作）
3. Excel を起動し、結合テーブルを A1 に1回で書き、名前を付けて保存
4. CSV を一括で移動、ログ、完了ダイアログ（DebugMode で省略）

見積もり
- 規模: 約 30 行、サブフロー 0、ループ 1 段
- 工数: 設計 10 分 / 組立 15 分 / 模擬テスト 10 分 / 実機 15 分
- リスク: (1) CSV の列が揃っていない → MergeDataTables の AddExtraColumns で吸収 (2) 読取失敗 → 2回再試行して件数を記録し続行 (3) Excel が既に開いている → 別インスタンスを非表示で起動するので影響なし
- 実行時間: 50 件 × 0.3 秒 + Excel 起動 3 秒 ≒ 20 秒

検証方法: Chat モード想定。模擬貼付テスト（判定表）→ 利用者がダミーフローに貼付 → DebugMode=True で実行 → 本番入口で1回
→ GO でよければ着手します。既定値のまま進めてよい項目: パス、エンコード UTF-8、区切り（システム既定）
