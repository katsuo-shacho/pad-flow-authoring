# Contributing

Pull requests are welcome. To keep the project safe to publish, every contribution must satisfy:

1. **Provenance**: anything copied verbatim must come from a source with an explicit permissive license (MIT, BSD, Apache-2.0, CC BY, CC0). Add it to THIRD_PARTY_NOTICES.md with URL, license and copyright holder. Material with no license, or under GPL/CC BY-SA/CC BY-NC, may be linked but not copied.
2. **Behaviour, not product**: record what PAD does (identifiers, argument names, enum values, error names, paste outcomes) with the PAD build you observed it on. Do not add screenshots, icons, logos, decompiled or internal material.
3. **No secrets, no private data**: no credentials, connection strings, hostnames, file paths or data from your employer or customers. Use placeholders (`C:\Reports\in.txt`, `https://example.com`).
4. **Verified in the designer**: new Robin lines must have been pasted into a real PAD designer. State the build number.
5. **Attribution stays**: do not remove source lines or license headers from generated files. Regenerate with the scripts rather than hand-editing `knowledge/actions/`, `knowledge/robin/`, `knowledge/robin-powerfx/`.

By contributing you agree your contribution is licensed under the project licenses (docs CC BY 4.0, scripts MIT).
